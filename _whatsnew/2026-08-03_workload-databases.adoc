=== 在精心设计的分析中对 Oracle 和 Microsoft SQL Server 的配置更改

在架构完善的分析中，多个数据库配置已合并并重命名为以下配置。

* *块设备空间管理*：包括空间预留、空间分配和部分预留
* *存储效率*：包括压缩、重复数据删除和缩减
* *分层/TCO 优化*：包括分层策略和分层最短冷却天数
* *计划本地 Snapshots*：包括 Snapshot 策略
